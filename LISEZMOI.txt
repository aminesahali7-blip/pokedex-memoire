Pokédex Mémoire — version à héberger (pas de limite de taille)
1. Mets TOUS les fichiers de ce dossier à la racine d'un site (ex. dépôt GitHub → Settings → Pages → branche main, dossier /root).
2. Ouvre l'adresse dans Safari → Partager → « Sur l'écran d'accueil » : l'appli marche ensuite hors ligne.
3. Ta progression ne suit pas toute seule : dans l'ancienne version, Réglages → Exporter ; dans la nouvelle, Réglages → Importer.
Chaque nouvelle version : remplace simplement les fichiers, l'appli se met à jour toute seule (cache 99dc4a35db).

Synchronisation entre appareils (facultatif) :
- Elle utilise une petite fonction Netlify (dossier netlify/, package.json, netlify.toml) qui n'est PAS installée par le glisser-déposer.
- Le plus simple : mets ce dossier dans un dépôt GitHub, puis sur Netlify « Add new site → Import from Git ». Netlify installe la fonction tout seul à chaque mise à jour du dépôt.
- Ou avec Netlify CLI : `npm i -g netlify-cli`, puis dans ce dossier `netlify deploy --prod`.
- Ensuite, dans l'appli : Réglages → ☁️ Synchronisation → Activer, et entre la même clé sur ton autre appareil.
